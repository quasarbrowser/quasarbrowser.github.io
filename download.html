Quickstart

Install in Four Steps

01

Download the installer

Click Download Installer. The file is about 461 MB - the complete browser bundle, so give the first download a minute. Hosted on GitHub Releases.

02

Run Quasar Browser Setup.exe

SmartScreen may say "Windows protected your PC" (the app is not code-signed yet) - choose More info, then Run anyway. No administrator rights are required.

03

Launch Quasar

Open Quasar from the Start Menu or desktop. The first launch takes about 30 seconds while local data is prepared - later starts are quick.

04

Turn on Void Mode (optional)

Open Void Mode from the toolbar for fully anonymous, four-hop browsing. It is off by default so normal browsing stays fast.
